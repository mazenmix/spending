# MX Spend

Fast, mobile-first daily expense logger for Philippine pesos.

- Enter only the amount and your own description — no preset categories.
- Today resets automatically at local midnight while all previous days stay in Reports.
- PHP is the main currency; USD is shown as a smaller live estimate with cached offline fallback.
- Daily, weekly, monthly and all-history reports.
- Share reports as plain text or download `.txt` files.
- Installable/offline PWA.
- Edit, delete, undo, JSON backup and restore.

Expense data is stored locally on the device/browser. Export a backup before clearing browser data or changing phones.
